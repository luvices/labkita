# Atribusi Lisensi & Hak Cipta Komponen Antarmuka (Credits)

Proyek **LabKita Linux 0.2** menggunakan komponen antarmuka sumber terbuka (*open source*) yang berlisensi bebas dan legal. Proyek ini secara ketat **tidak menggunakan aset berpemilik (*proprietary*) milik Apple Inc.** (seperti logo Apple, font San Francisco / SF Pro, maupun wallpaper macOS asli). Seluruh aset telah digantikan dengan padanan berbasis sumber terbuka yang terstandarisasi.

---

## 1. WhiteSur GTK Theme
- **Pengembang Asli:** Vince Liuice ([vinceliuice](https://github.com/vinceliuice))
- **Repositori:** [https://github.com/vinceliuice/WhiteSur-gtk-theme](https://github.com/vinceliuice/WhiteSur-gtk-theme)
- **Lisensi:** GNU General Public License v3.0 (GPL-3.0)
- **Penggunaan:** Tema GTK 3, GTK 4, dan GNOME Shell dengan sudut jendela membulat (*rounded corners*), tombol kontrol jendela di sisi kiri, dan panel navigasi atas yang bersih. Dikonfigurasi dengan opsi ikon non-Apple (`-i simple`).

## 2. WhiteSur Icon Theme
- **Pengembang Asli:** Vince Liuice ([vinceliuice](https://github.com/vinceliuice))
- **Repositori:** [https://github.com/vinceliuice/WhiteSur-icon-theme](https://github.com/vinceliuice/WhiteSur-icon-theme)
- **Lisensi:** GNU General Public License v3.0 (GPL-3.0)
- **Penggunaan:** Set ikon aplikasi, folder, dan simbolik modern untuk lingkungan desktop Linux.

## 3. WhiteSur Cursor Theme
- **Pengembang Asli:** Vince Liuice ([vinceliuice](https://github.com/vinceliuice))
- **Repositori:** [https://github.com/vinceliuice/WhiteSur-cursors](https://github.com/vinceliuice/WhiteSur-cursors)
- **Lisensi:** GNU General Public License v3.0 (GPL-3.0)
- **Penggunaan:** Tema kursor tetikus dengan animasi halus bergaya modern.

## 4. Tipografi Inter Font Family
- **Perancang Font:** Rasmus Andersson ([rsms](https://rsms.me/inter/))
- **Repositori:** [https://github.com/rsms/inter](https://github.com/rsms/inter)
- **Lisensi:** SIL Open Font License, Version 1.1 (OFL-1.1)
- **Penggunaan:** Font antarmuka sistem (pengganti font San Francisco/SF Pro) untuk seluruh elemen antarmuka desktop, dokumen, dan bilah judul jendela (*titlebar*).

## 5. Wallpaper Orisinal LabKita Linux
- **Perancang:** Tim Pengembang LabKita Linux (Dafa Zahran, Rafly Fauzi Pratama, Muhammad Ilham Rizky, Vadien Athallah Lukman)
- **Lisensi:** Creative Commons Attribution 4.0 International (CC-BY 4.0) / MIT
- **Deskripsi:** Desain gradien mesh orisinal dengan transisi warna *deep navy slate* ke *ocean cyan*, *indigo violet*, dan *emerald teal*, dilengkapi lambang geometris LabKita Linux. Dibuat secara mandiri tanpa menggunakan wallpaper Apple.
