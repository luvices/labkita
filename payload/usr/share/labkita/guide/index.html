1 Siapkan Folder Latihan

Pertama, buka Terminal — tekan Ctrl + Alt + T atau klik ikonnya di dock bawah. Lalu jalankan perintah ini untuk membuat folder kerja dan menyalin semua contoh kode ke dalamnya:

Ketik di Terminal:
mkdir -p "$HOME/Praktikum"
cp -n /usr/share/labkita/examples/* "$HOME/Praktikum/"
cd "$HOME/Praktikum"
ls
💡 Tips Kalau mau nulis kode, buka Geany — editor ringan yang sudah siap untuk C dan Python. Caranya: klik ikon Geany di dock, atau cari di menu aplikasi. Jangan lupa simpan file (Ctrl + S) sebelum dijalankan.

2 Jalankan Program Python

Python 3 sudah terpasang dan langsung bisa dipakai — tidak perlu install apa-apa. Coba jalankan contoh yang sudah ada:

Program sederhana:
cd "$HOME/Praktikum"
python3 hello.py

Output yang kamu lihat: Halo dari LabKita Linux!

Contoh multithreading:
python3 thread_demo.py

Di program thread_demo.py, kamu akan melihat dua thread berjalan bersamaan dalam satu proses yang sama (PID-nya identik). Ini yang membedakan thread dari proses biasa.

📌 Catatan Mau eksplorasi lebih lanjut? Buka file thread_demo.py di Geany, baca komentar di dalam kode, coba ubah jumlah iterasi atau tambahkan thread baru, lalu jalankan lagi!

3 Kompilasi dan Jalankan Program C

GCC (GNU C Compiler) sudah tersedia. Proses kerjanya: tulis kode → kompilasi → jalankan hasil kompilasi.

Program hello world C:
cd "$HOME/Praktikum"
gcc -Wall -Wextra hello.c -o hello
./hello
Contoh alokasi memori dinamis:
gcc -Wall -Wextra memory_demo.c -o memory_demo
./memory_demo

Program memory_demo.c menunjukkan cara memesan ruang di memori Heap pakai malloc(), membaca dan mengisi datanya, lalu mengembalikan memori itu ke sistem pakai free(). Ini penting supaya programmu tidak bocor memori (memory leak).

❓ Apa itu -Wall -Wextra? Dua flag itu memerintahkan GCC supaya kasih tahu kalau ada bagian kode yang mencurigakan atau rawan bug, meski kode masih bisa dikompilasi. Biasakan pakai keduanya dari awal!

4 Pelajari Konsep Proses & Thread

Dua contoh di bawah ini menunjukkan dua cara berbeda menjalankan tugas secara bersamaan di sistem operasi Linux.

Contoh proses (fork / multiprocessing):
python3 "$HOME/Praktikum/processes.py"
ps -u "$USER" -o pid,ppid,comm,state

🔀 Proses (processes.py)

  • Setiap proses anak punya PID sendiri
  • PPID-nya menunjuk ke proses induk
  • Memori terpisah (tidak berbagi)
  • Lebih aman, lebih terisolasi

🧵 Thread (thread_demo.py)

  • Semua thread berbagi PID yang sama
  • Berjalan dalam satu proses induk
  • Memori dibagi bersama
  • Lebih ringan, cocok untuk tugas kecil
💡 Cara ceknya Jalankan processes.py, lalu lihat output ps. Perhatikan kolom PID dan PPID — kamu akan lihat proses anak punya nomor berbeda dari induknya. Bandingkan hasilnya dengan thread_demo.py yang PID-nya sama semua.

5 Pakai Ruang Kerja Sementara

LabKita menyediakan folder /run/labkita yang berbasis RAM — tulis-bacanya sangat cepat, cocok untuk menyimpan file sementara saat praktikum.

Coba sendiri:
ls -ld /run/labkita
echo "Ini catatan sementara saya" > /run/labkita/coba.txt
cat /run/labkita/coba.txt
systemctl status labkita-runtime.service --no-pager
⚠️ Penting — jangan simpan tugas di sini! Semua isi /run/labkita akan hilang otomatis begitu komputer dimatikan atau di-restart. Simpan file penting seperti kode program kamu di ~/Praktikum.

Satu lagi: program hasil kompilasi (file biner seperti ./hello) harus dijalankan dari ~/Praktikum, bukan dari /run/labkita, karena folder /run dikunci sistem agar tidak bisa menjalankan program (istilahnya noexec).

6 Butuh Bantuan?

Semua referensi dan dokumentasi tersedia offline — tidak perlu internet sama sekali:
