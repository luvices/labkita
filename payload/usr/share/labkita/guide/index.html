Modul 01

Orientasi Shell, Diagnostik, & Manajemen Berkas

Buka Terminal lewat Ctrl + Alt + T atau ikon terminal di dock bawah. Salin berkas contoh bawaan dari /usr/share/labkita/examples/ ke folder pribadi ~/Praktikum, lalu jalankan pemeriksaan sistem.

Terminal Bash
mkdir -p "$HOME/Praktikum"
cp -n /usr/share/labkita/examples/* "$HOME/Praktikum/"
cd "$HOME/Praktikum"
ls -la
labkita-check
Tugas 1: Struktur direktori & hak akses
  1. Di dalam ~/Praktikum, buat subdirektori tugas1/src, tugas1/bin, dan tugas1/out dengan satu perintah mkdir -p.
  2. Ubah izin folder tugas1/out menjadi privat pemilik saja (chmod 700) dan cek hasilnya memakai stat -c "%a %n" tugas1/*.
  3. Salin hello.c ke tugas1/src/ lalu catat perbedaan izin sebelum dan sesudah.
Modul 02

Pemrograman Python Dasar & Pengolahan Berkas

Python 3 berjalan langsung di terminal atau lewat editor Geany. Mulai dengan menguji skrip contoh hello.py.

Terminal Bash
python3 ~/Praktikum/hello.py
Tugas 2: Rekap nilai mahasiswa offline
  1. Buat berkas data ~/Praktikum/nilai.txt berisi minimal 6 baris format Nama,Nilai (contoh: Andi,85).
  2. Tulis skrip rekap_nilai.py yang membaca nilai.txt, menghitung rata-rata, nilai tertinggi, dan nilai terendah.
  3. Simpan ringkasan hasil ke berkas baru ~/Praktikum/ringkasan.txt dan tampilkan isinya lewat cat ringkasan.txt.
Modul 03

Bahasa C, Alokasi Memori Dinamis, & Debugging GDB

Gunakan flag peringatan ketat -Wall -Wextra dan simbol debug -g saat mengompilasi program C. Program memory_demo.c mendemonstrasikan alokasi blok heap dengan malloc() dan pembebasan dengan free().

Terminal Bash
cd ~/Praktikum
gcc -Wall -Wextra -g hello.c -o hello && ./hello
gcc -Wall -Wextra -g memory_demo.c -o memory_demo && ./memory_demo
Tugas 3: Eksperimen memori & breakpoint GDB
  1. Salin memory_demo.c ke tugas_mem.c, ubah agar menerima jumlah elemen dari input pengguna (scanf) dan mengisi deret kuadrat.
  2. Tambahkan fungsi cetak_statistik() untuk mencari nilai maksimum di array heap tersebut.
  3. Jalankan biner hasil kompilasi di dalam gdb ./tugas_mem, pasang breakpoint (break main), jalankan per baris (next), lalu cetak nilai pointer (print larik_dinamis).
Modul 04

Manajemen Proses, fork(), & Pengamatan PID/PPID

Setiap proses Linux memiliki nomor unik PID dan proses induk PPID. Berkas processes.py memakai fork agar proses anak menunjuk langsung ke proses induknya.

Terminal Bash
python3 ~/Praktikum/processes.py
Tugas 4: Pohon proses 4 worker
  1. Buat multi_worker.py yang meluncurkan 4 proses anak bersamaan, masing-masing tidur selama 5 detik (time.sleep(5)) agar sempat diamati.
  2. Saat skrip berjalan, buka tab terminal kedua dan jalankan ps -ef --forest | grep python3 untuk membuktikan satu PID induk membawahi 4 PID anak.
  3. Catat hasil pengamatan PID dan PPID kelima proses tersebut.
Modul 05

Multithreading, Shared Memory, & Sinkronisasi Lock

Berbeda dengan proses terpisah, seluruh thread berada di dalam satu PID dan berbagi ruang memori global yang sama. Akses serentak ke variabel yang sama dapat memicu race condition.

Terminal Bash
python3 ~/Praktikum/thread_demo.py
Tugas 5: Simulasi & perbaikan race condition
  1. Tulis race_lab.py berisi 4 thread yang masing-masing menaikkan penghitung global saldo = saldo + 1 sebanyak 100.000 kali (target akhir seharusnya 400.000).
  2. Bandingkan hasil eksekusi tanpa threading.Lock() dan dengan with lock:.
  3. Catat durasi waktu masing-masing pendekatan menggunakan time.perf_counter().
Modul 06

Isolasi Akun Praktikan & Ruang Kerja RAM (tmpfs)

Direktori /run/labkita dimuat di RAM memakai filesystem tmpfs dan berizin sticky bit 1777. Seluruh berkas di sini hilang saat sistem dimatikan, sedangkan izin /home/praktikan terkunci 0700 dan tidak memiliki hak sudo.

Terminal Bash
id
stat -c "%a %U %n" "$HOME" /run/labkita
df -h /run/labkita
mount | grep "on /run "

Disimpan permanen

~/Praktikum
Simpan kode sumber C/Python dan hasil biner terkompilasi agar tetap ada setelah reboot.

Temporer RAM (noexec)

/run/labkita/$USER
Gunakan untuk log uji atau berkas data besar sementara. Jangan taruh executable di sini karena /run dipasang noexec.

Tugas 6: Pengujian sticky bit & tmpfs
  1. Buat folder kerja sementara mkdir -p /run/labkita/$USER dan tulis file log pengujian sebesar 5 MB memakai dd if=/dev/zero of=/run/labkita/$USER/uji.bin bs=1M count=5.
  2. Amati perubahan pemakaian di df -h /run/labkita, lalu hapus lagi berkas sementara tersebut.
  3. Uji mencoba menyalin biner ~/Praktikum/hello ke /run/labkita/$USER/ dan jalankan untuk memverifikasi proteksi kernel noexec.
Modul 07

Proyek Mini Integrasi C + Python (Offline End-to-End)

Gabungkan pemrograman C (komputasi atau pencatat data cepat) dengan Python (olah data) dalam satu alur pipa kerja lokal tanpa jaringan.

Tugas 7: Generator data C & penganalisis Python
  1. Buat program C gen_log.c yang menulis 50 baris data simulasi suhu (detik,suhu) ke berkas /run/labkita/$USER/suhu.csv.
  2. Kompilasi dengan gcc -Wall -Wextra -O2 gen_log.c -o ~/Praktikum/gen_log.
  3. Buat skrip Python analisa_suhu.py untuk membaca CSV tersebut, menghitung rata-rata, menandai angka di atas ambang batas, lalu jalankan berurutan dengan perintah ./gen_log && python3 analisa_suhu.py.

Alasan biner tidak dijalankan dari /run/labkita
