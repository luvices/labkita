1. Menyiapkan Folder Latihan

Buka aplikasi Terminal (pintasan Ctrl + Alt + T), lalu siapkan folder praktikum pribadi di direktori home Anda:

mkdir -p "$HOME/Praktikum"
cp -n /usr/share/labkita/examples/* "$HOME/Praktikum/"
cd "$HOME/Praktikum"
ls -la
Catatan: Buka editor Geany dari dock atau menu aplikasi untuk menulis kode program. Simpan berkas sebelum menjalankan kode di terminal.

2. Menjalankan Kode Python

Eksekusi kode Python 3 secara langsung melalui terminal tanpa perlu mengunduh paket daring:

cd "$HOME/Praktikum"
python3 hello.py
python3 thread_demo.py

Berkas hello.py menampilkan pesan sambutan dasar, sedangkan thread_demo.py mendemonstrasikan eksekusi multithreading di mana beberapa thread pekerja berjalan secara konkuren dalam satu proses sistem operasi.

3. Mengompilasi dan Menjalankan Bahasa C

Gunakan GNU C Compiler (GCC) untuk mengompilasi berkas kode sumber C ke dalam binary executable:

cd "$HOME/Praktikum"
gcc -Wall -Wextra hello.c -o hello
./hello

gcc -Wall -Wextra memory_demo.c -o memory_demo
./memory_demo

Argumen -Wall -Wextra menyalakan seluruh peringatan standar kompiler untuk membantu mendeteksi kesalahan penulisan kode sedini mungkin. Berkas memory_demo.c mencontohkan alokasi memori dinamis pada segmen Heap menggunakan malloc() dan pembebasannya dengan free().

4. Mengamati Konsep Proses dan Thread

Sistem operasi mengelola konkurensi melalui proses dan thread. Pelajari perbedaannya melalui contoh kode yang disediakan:

python3 "$HOME/Praktikum/processes.py"
ps -u "$USER" -o pid,ppid,comm,state

Pada processes.py, proses anak dibuat menggunakan mekanisme fork dengan PID independen dan PPID yang merujuk ke proses induk. Bandingkan dengan thread_demo.py di mana seluruh thread berbagi PID dan ruang alamat memori yang sama.

5. Memanfaatkan Ruang Kerja Sementara (/run/labkita)

Sistem menyediakan direktori RAM Disk berbasis memori (tmpfs) di /run/labkita dengan hak akses 1777 (sticky bit):

ls -ld /run/labkita
echo "Catatan praktikum sementara" > /run/labkita/scratch.txt
cat /run/labkita/scratch.txt
systemctl status labkita-runtime.service --no-pager
Penting: Partisi /run dipasang dengan opsi noexec oleh sistem keamanan Linux, sehingga berkas biner executable harus tetap dijalankan dari folder ~/Praktikum. Gunakan /run/labkita untuk berkas scratch atau data temporer. Seluruh isi /run/labkita akan terhapus otomatis saat komputer dimatikan atau direstart.

6. Akses Manual dan Diagnostik Offline

Ketika tidak ada sambungan internet, gunakan manual bawaan Linux dan utilitas pemeriksaan sistem:

labkita-check      # Memverifikasi seluruh kesiapan sistem praktikum
man gcc            # Manual resmi kompiler GCC
man 3 printf       # Manual pustaka fungsi printf C
man 3 malloc       # Manual alokasi memori dinamis C
python3 -m pydoc   # Dokumentasi interaktif fungsi Python

Tekan tombol q pada keyboard untuk keluar dari tampilan manual.
