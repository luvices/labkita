1. Folder Kerja 2. Pemrograman Python 3. Pemrograman C 4. Multiprocessing 5. Ruang Sementara 6. Bantuan Offline

1. Menyiapkan Folder Latihan

Buka aplikasi Terminal (pintasan Ctrl + Alt + T), lalu siapkan folder praktikum pribadi di direktori home Anda:

mkdir -p "$HOME/Praktikum"
cp -n /usr/share/labkita/examples/* "$HOME/Praktikum/"
cd "$HOME/Praktikum"
geany hello.py &
Catatan: Geany adalah editor teks pemrograman yang ringan dan sudah siap pakai. Simpan berkas sebelum menjalankan kode di terminal.

2. Menjalankan Kode Python

Eksekusi kode Python 3 secara langsung melalui terminal tanpa perlu mengunduh package manager online:

cd "$HOME/Praktikum"
python3 hello.py

Keluaran standar: Halo dari LabKita Linux!. Silakan modifikasi isi pesan di Geany, simpan, dan jalankan kembali.

3. Mengompilasi dan Menjalankan Bahasa C

Gunakan GNU C Compiler (GCC) untuk mengompilasi berkas kode sumber C ke dalam binary executable:

cd "$HOME/Praktikum"
gcc -Wall -Wextra hello.c -o hello
./hello

Perintah -Wall -Wextra menyalakan seluruh peringatan standar kompiler untuk membantu mendeteksi kesalahan penulisan kode sejak awal.

4. Mengamati Konsep Proses Sistem Operasi

Berkas processes.py mendemonstrasikan pembuatan proses anak secara paralel (forking/multiprocessing):

python3 "$HOME/Praktikum/processes.py"
ps -u "$USER" -o pid,ppid,comm,state

Amati nomor Process ID (PID) dan Parent Process ID (PPID) pada terminal untuk memahami hierarki proses pada sistem operasi Linux.

5. Memanfaatkan Ruang Kerja Sementara (/run/labkita)

Sistem menyediakan direktori RAM Disk berkecepatan tinggi di /run/labkita dengan izin 1777 (sticky bit):

ls -ld /run/labkita
cp hello "$HOME/Praktikum/"
systemctl status labkita-runtime.service --no-pager
Penting: Seluruh berkas yang disimpan di dalam /run/labkita akan terhapus otomatis saat sistem direstart atau dimatikan. Simpan tugas penting Anda di ~/Praktikum.

6. Akses Manual dan Diagnostik Offline

Ketika tidak ada sambungan internet, gunakan manual bawaan Linux dan utilitas pemeriksaan sistem:

labkita-check      # Memverifikasi 14 item kesiapan sistem praktikum
man gcc            # Manual resmi kompiler GCC
man 3 printf       # Manual standar library bahasa C
python3 -m pydoc   # Dokumentasi interaktif fungsi Python

Tekan tombol q pada keyboard untuk keluar dari tampilan manual.
