Siapkan folder latihan

Buka Terminal, lalu salin contoh ke folder pribadi agar dapat diedit.

mkdir -p "$HOME/Praktikum"
cp -n /usr/share/labkita/examples/* "$HOME/Praktikum/"
cd "$HOME/Praktikum"
geany hello.py

Geany adalah editor. Simpan perubahan sebelum menjalankan program di terminal.

Jalankan Python

cd "$HOME/Praktikum"
python3 hello.py

Keluaran awal: Halo dari LabKita Linux! Ubah pesan, simpan, lalu jalankan lagi.

Buka dokumentasi Python lokal

Compile bahasa C

cd "$HOME/Praktikum"
gcc -Wall -Wextra hello.c -o hello
./hello

GCC mengubah kode C menjadi program yang dapat dijalankan. Edit pesan di dalam puts lalu compile ulang.

Amati proses sistem operasi

python3 "$HOME/Praktikum/processes.py"
ps -u "$USER" -o pid,ppid,comm
free -h
df -h
systemctl status labkita-runtime.service --no-pager

Contoh Python membuat dua proses anak. Bandingkan PID dan PPID pada keluarannya. free menampilkan memori, sedangkan df menampilkan penyimpanan.

/run/labkita adalah ruang sementara bersama dengan sticky bit. Isinya hilang saat reboot atau layanan dihentikan. Simpan tugas di folder pribadi.

Bantuan tanpa internet

man gcc
man 3 printf
python3 -m pydoc print
labkita-check
