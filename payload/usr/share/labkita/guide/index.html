1 Siapkan Folder Latihan

Buka aplikasi Terminal lewat pintasan Ctrl + Alt + T atau klik ikon terminal di dock bawah. Salin seluruh contoh berkas praktikum bawaan sistem ke folder kerja pribadi Anda di ~/Praktikum:

Jalankan di Terminal:
mkdir -p "$HOME/Praktikum"
cp -n /usr/share/labkita/examples/* "$HOME/Praktikum/"
cd "$HOME/Praktikum"
ls -la

Hasil perintah ls -la akan menampilkan berkas latihan: hello.c, hello.py, memory_demo.c, processes.py, dan thread_demo.py.

💡 Tips Menulis Kode: Gunakan editor Geany yang ringan dan sudah disiapkan khusus praktikum C dan Python. Anda bisa membukanya melalui ikon di dock bawah atau menu aplikasi. Jangan lupa simpan berkas (Ctrl + S) sebelum menjalankan kode di terminal.

2 Menjalankan Program Python

Python 3 sudah terpasang dan siap digunakan tanpa perlu koneksi internet maupun package manager tambahan:

Contoh dasar (hello world):
cd "$HOME/Praktikum"
python3 hello.py

Keluaran standar: Halo dari LabKita Linux!

Contoh multithreading:
python3 thread_demo.py

Program thread_demo.py menggunakan modul standar threading untuk menjalankan dua thread pekerja secara bersamaan (konkuren). Perhatikan bahwa kedua thread berjalan di bawah Process ID (PID) yang sama karena berbagi ruang memori yang identik.

📌 Eksplorasi Mandiri: Buka thread_demo.py di Geany, amati komentar penjelas di dalam kode, dan coba ubah jumlah iterasi atau tambahkan thread ketiga.

3 Mengompilasi dan Menjalankan Bahasa C

Kompiler GCC (GNU C Compiler) sudah terpasang lengkap dengan pustaka standar C. Alur kerja praktikum C: tulis kode → kompilasi → jalankan biner.

Program dasar C:
cd "$HOME/Praktikum"
gcc -Wall -Wextra hello.c -o hello
./hello
Contoh alokasi memori dinamis (Heap):
gcc -Wall -Wextra memory_demo.c -o memory_demo
./memory_demo

Program memory_demo.c mendemonstrasikan cara memesan memori di Heap dengan malloc(), memeriksa validitas pointer (cek NULL), menggunakan memori tersebut, lalu mengembalikannya ke sistem operasi dengan free() serta menyetel pointer ke NULL untuk mencegah dangling pointer.

❓ Mengapa memakai -Wall -Wextra? Kedua opsi ini mengaktifkan seluruh peringatan standar kompiler. Jika ada kode yang berpotensi menimbulkan bug atau kebocoran memori, GCC akan langsung memberikan peringatan saat kompilasi.

4 Mempelajari Konsep Proses & Thread

Dua contoh program di bawah ini memperlihatkan perbedaan mendasar antara model proses terpisah (multiprocessing) dan model thread (multithreading) pada sistem operasi Linux:

Uji multiprocessing (fork):
python3 "$HOME/Praktikum/processes.py"
ps -u "$USER" -o pid,ppid,comm,state

🔀 Proses (processes.py)

  • Setiap proses anak memiliki nomor PID sendiri.
  • PPID menunjuk ke nomor PID proses induk.
  • Ruang memori terisolasi antar proses.
  • Kerusakan di satu proses tidak langsung merusak proses lain.

🧵 Thread (thread_demo.py)

  • Semua thread berbagi PID yang sama.
  • Berjalan di dalam ruang alamat satu proses.
  • Memori heap dan data dibagi bersama.
  • Lebih ringan, tetapi butuh sinkronisasi yang cermat.
💡 Pengamatan Terminal: Jalankan processes.py lalu periksa kolom PID dan PPID pada perintah ps. Bandingkan dengan keluaran thread_demo.py di mana nomor PID-nya tetap sama untuk seluruh thread.

5 Memanfaatkan Ruang Kerja Sementara (/run/labkita)

LabKita menyediakan RAM Disk berkecepatan tinggi di folder /run/labkita (tmpfs) dengan izin akses bersama (sticky bit 1777). Folder ini sangat cocok untuk berkas sementara atau uji coba cepat yang tidak perlu disimpan permanen.

Uji coba RAM disk:
ls -ld /run/labkita
echo "Catatan praktikum sementara" > /run/labkita/coba.txt
cat /run/labkita/coba.txt
systemctl status labkita-runtime.service --no-pager
⚠️ Perhatian Penting: Seluruh isi di dalam /run/labkita berada di memori RAM dan akan hilang secara otomatis saat komputer dimatikan atau di-restart. Selalu simpan kode program dan laporan tugas Anda di ~/Praktikum.

Partisi /run dipasang dengan opsi keamanan noexec oleh sistem operasi. Oleh karena itu, berkas biner executable (seperti ./hello atau ./memory_demo) harus dikompilasi dan dijalankan dari ~/Praktikum, bukan dari /run/labkita.

Bila Anda membutuhkan referensi saat praktikum tanpa sambungan internet, gunakan manual bawaan Linux dan utilitas pemeriksaan mandiri:

Perintah diagnostik & manual:

man 3 printf             # Dokumentasi fungsi printf bahasa C
man 3 malloc             # Dokumentasi alokasi memori dinamis (malloc/free)
python3 -m pydoc math    # Dokumentasi modul Python (ganti math sesuai kebutuhan)
📖 Navigasi Manual (man page): Gunakan tombol Panah Atas / Bawah atau Spasi untuk menggulir halaman. Ketik /kata_kunci lalu tekan Enter untuk mencari kata. Tekan tombol q untuk keluar dari tampilan manual.
